# Metadata Standards

## Candidate Metadata

- candidate_id: Unique candidate identifier
- job_id: Unique job identifier
- model_version: AI model version used
- timestamp: Date and time of processing

## Example

{
    "candidate_id": "C001",
    "job_id": "J001",
    "model_version": "v1.0",
    "timestamp": "2026-10-07T12:00:00"
}
