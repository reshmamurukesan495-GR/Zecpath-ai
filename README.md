# Zecpath AI
Zecpath is an AI-powered job portal designed to automate and streamline the hiring process.

# project Structure
-'data/' - Data files and sample inputs
-'parsers/' - Resume parsing and information extraction
-'ats_engine/'- ATS matching and scoring
-'screening_ai/'- Candidate screening
-'interview_ai/'- AI interview processing
-'scoring/'- Candidate scoring and decision logic
-'utils/'- Configuration and logging utilities
-'tests/'- Test cases

# Environment
The project uses a python virtual environment.

# Main Technologies
-Python
-FastAPI
-Pandas
-NumPy
-Scikit-learn
-Pytest
